# BLHA Phase 2C.6 — Frozen Discohook Standard

Canonical hosted graphics for BLHA Discohook messages.

- Headers: 1600x300
- Header embed side color: #2B2D31
- Footer: transparent 1600x180 PNG (legacy filename retained)
- Gold: #FFB81C
- Cream: #F4EFE4
- Right-side rink circle is fully inset.
- BLHA lettering is white with black/gold keylines and no white logo card.
- All manual Discohook JSON templates are normalized by tools/normalize_discohook_templates.py.

This Phase 2C.6 visual format is frozen. Future content may change; the layout standard should not change without an explicit design revision.
